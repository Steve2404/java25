# Algorithmus-Training — Kapitel 4

Nur Aufgaben. Lösungen: [../solutions/algorithms/README.md](../solutions/algorithms/README.md)

## A01 — Summe 1..n
Berechne mit einer Schleife die Summe von 1 bis `n`.  
**Constraint:** keine Formel `n*(n+1)/2`.

## A02 — Fakultät
Berechne für `n >= 0` die Fakultät mit `long`.  
**Reflexion:** Ab wann wird Overflow relevant?

## A03 — Ziffernsumme
Berechne die Quersumme einer nichtnegativen ganzen Zahl nur mit `%` und `/`.  
Beispiel: `538 -> 16`.

## A04 — Zahl umdrehen
Drehe die Dezimalziffern einer positiven Zahl um.  
Beispiel: `12034 -> 43021`.

## A05 — Primzahl
Entscheide mit Test bis `sqrt(n)`, ob `n` prim ist.

## A06 — Euklidischer GGT
Berechne den GGT zweier positiver Zahlen mit dem Modulo-Verfahren.

### Standard-Arbeitsauftrag
Für jeden Algorithmus:
1. Eingabe-/Ausgabebeispiele schreiben.
2. Zustandsvariablen festlegen.
3. Pseudocode schreiben.
4. Java-Skelett mit TODO erstellen.
5. Mindestens drei Randfälle testen.
6. Laufzeit grob begründen.
